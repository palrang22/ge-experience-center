## 원본 7단계 공통 구조 (압축 기준)

모든 도메인이 동일한 7단계 패턴을 따른다:

1. **Foundation / Catalog Discovery** — 데이터 카탈로그 메타데이터 탐색 (CEO 오프닝, 다소 기술적·메타 설명)
2. **Interactive Dashboard** — 브라우저에서 열리는 인터랙티브 경영진 대시보드
3. **Cross-Source Discovery (WOW Moment)** — 외부 파일 + 내부 BigQuery 교차 대조로 부서 간 단절이 숨겨온 리스크 적발 (📎 첨부파일 필수)
4. **Vision & HITL** — 현장 수기 문서 OCR 판독 + 승인 워크플로우 (도메인에 따라 📎 첨부파일 있음/없음이 갈림)
5. **자율 시뮬레이터 개발 (Pattern B)** — 백그라운드 샌드박스에서 Python 분석 + 웹앱 코딩, 소요시간 김
6. **Cron 모니터링 등록** — 정기 스케줄러 등록, 반복적·저임팩트
7. **웹 리서치 + 전략 보고서 (Pattern A Finale)** — 실시간 웹 리서치 + 내부 데이터 결합, 이사회 보고 수준 산출물

**컷 기준**: 5(소요시간 김) · 6(반복적/저임팩트) · 1(메타 설명, 체험 초입에 불필요)은 전 도메인 공통으로 제외.
2(대시보드)와 4(Vision/HITL)는 도메인별로 "4단계에 실제 📎 첨부파일이 있는가"(=진짜 비전 판독쇼가 있는가)에 따라 남기거나 뺐다 — 그 결과가 도메인마다 3~4단계로 자연스럽게 갈렸다(2026-09-17 결정: 획일적 4단계 통일 아님, 정확히 부합).
