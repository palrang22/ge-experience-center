# Phase 5 데모 데이터 결정 기록 (2026-09-17)

`docs/demo-scenarios.md` v2가 "원본 시나리오 그대로 재사용" 방향으로 확정되면서 생긴 후속 결정 2건. 답변은 이미 받았고, 이 문서는 기록용이다.

## Q1. 원본 데모 파일(한성정밀·대원정밀·씨네맥스 코리아 등 가상 회사명이 담긴 데이터)을 어떻게 처리할까요?

**답변: 원본 그대로 재사용.** 회사명/지명 리브랜딩 없이 그대로 다운로드해서 씀. → `public/demo-data/<domainId>/`에 원본 23개 파일(고유 기준) 그대로 저장 완료.

## Q2. Vision 단계 첨부 이미지 2개를 1개로 줄여서 체류시간을 단축할까요?

**답변: 2개 유지(원본 그대로).** 체류시간 단축보다 "여러 라인/사진을 한꺼번에 판독" 임팩트를 우선.

## Q3. 금융 도메인 Finale에서 2단계 파일을 4단계에서 다시 요구하는 UX (구현자 판단으로 처리)

`fss_retail_lending_guidelines_2026.pdf`는 금융 도메인 2단계(WOW)와 4단계(Finale) 양쪽에 쓰이는 동일 파일이다. 사용자에게 파일을 두 번 첨부하라고 요구하지 않고, `scenarios.ts`의 4단계 `expectedResult`에 "(첨부는 2단계와 동일 파일 재사용)"이라고 명시해서 진행자가 "이미 올린 파일 그대로 써도 된다"는 걸 바로 알 수 있게 처리함. 별도 UI 변경 없음.
